# SAPA - Sistem Akses Pengenalan Anggota
SAPA merupakan proyek akhir berkelompok berbasis Internet of Things (IoT) dalam bentuk gate yang mengintegrasikan model Artificial Intelligence (AI) untuk mendeteksi wajah. Sistem ini dirancang khusus sebagai kontrol akses modern yang beroperasi secara otomatis dan dapat dipantau melalui dashboard.

Sistem ini mengintegrasikan teknologi pemindaian biometrik wajah (face recognition), mikrokontroler ESP32, serta infrastruktur backend berbasis Python untuk menciptakan sistem smart gate yang efisien.
