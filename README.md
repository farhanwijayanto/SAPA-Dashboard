# SAPA - Sistem Akses Pengenalan Anggota
SAPA adalah sebuah proyek akhir berkelompok yang berbasis Internet of Things (IoT) dengan bantuan model Artificial Intelligence (AI) untuk deteksi wajah seseorang. SAPA dirancang khusus sebagai sistem kontrol akses modern yang otomatis dan terpantau melalui dashboard.

Sistem ini mengintegrasikan teknologi pemindaian biometrik wajah (face recognition), mikrokontroler ESP32, serta infrastruktur backend berbasis Python untuk menciptakan sistem smart gate yang efisien.
